Lulo's IT Kompetencer

Jeg kan mange ting med hardware og fysisk vedligeholdelse af computere. Dette inkluderer installation og udskiftning af vitale komponenter som grafikkort, harddiske og kølesystemer. Jeg mestrer PC-assembly fra bunden, herunder korrekt kabelføring og montering i kabinetter. Desuden håndterer jeg datastyring gennem fuld systembackup til eksterne enheder samt avanceret partitionering og optimering af drev via Windows Disk Management.

Operativsystemer og Support

Inden for software og support har jeg ekspertise i installation og konfiguration af forskellige Windows-versioner. Jeg arbejder med programmer som: Microsoft Word, Excel og PowerPoint. Jeg kan også bruge programmer som Movavi Video Converter. Jeg holder meget af at udfordre mig selv med nye ting og finde løsninger, så jeg kan bevare kvaliteten og essensen i eksempelvis video- eller fotoprojekter.

Jeg arbejder sikkert med systemadministration gennem enhedshåndtering, driveropdatering og generel optimering af systemydelse. Mine netværkskompetencer dækker opsætning og konfiguration af trådløse netværk og routere.

Software og Kreativ Udvikling

Mine softwarefærdigheder spænder fra administrativt arbejde til kreativ produktion. Jeg har teknisk kendskab til webudvikling gennem HTML og CSS. Jeg arbejder med grafisk layout i Canva og har arbejdet med freeCodeCamp. Jeg bruger Visual Studio Code til at bygge hjemmesider med HTML og CSS. Ud over computer og webdesign er jeg inspireret af at skrive i Google Docs. Jeg bruger min fantasi og kreativitet til at skabe nye projekter. Mit næste projekt bliver JavaScript.

Min beskæftigelse

Jeg arbejder hos Center for Autisme på et beskyttet beskæftigelsestilbud, hvor jeg får mulighed for at være kreativ med IT og PC. Det passer rigtig godt til mig. Center for Autisme er et sted, hvor man hurtigt kan skabe venskaber, opbygge tillid og møde forståelse for alle omkring en.
