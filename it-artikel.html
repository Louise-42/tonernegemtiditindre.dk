IT-værksted – Programmer til opstart af alle typer pc

At eje en pc kræver, at man holder den ved lige, men det kan være svært, hvis man er ny. Hvor starter man så?

Mange vil nok sige, at antivirus er en høj prioritet. En god start kan være et program som Wise Care 365, der kan fjerne unødvendige filer og hjælpe computeren med en hurtigere opstart.

Et program, mange kender, er Google Chrome, som er en gratis webbrowser til internettet. Firefox er en anden gratis og populær browser.

Malwarebytes bør også være på listen over nyttige programmer, da det kan finde spyware og andre sikkerhedstrusler.

Wise Program Uninstaller er et nyttigt program, som nemt kan fjerne unødvendig software fra computeren.

VLC Media Player er et godt videoprogram, der kan afspille næsten alle typer mediefiler.

Hardware

RAM er computerens arbejdshukommelse. Hvis du ser videoer, redigerer eller spiller spil, kan det kræve mere RAM for at computeren kører hurtigt og stabilt.

Hvis din pc bliver langsom eller fryser, kan det skyldes for lidt RAM eller en langsom harddisk. En SSD kan ofte give computeren nyt liv.

CPU'en er computerens hjerne og styrer programmer, grafikkort og andre komponenter.

Databaser og XAMPP

XAMPP bruges til at oprette databaser med SQL og MySQL. Det kan bruges til at holde styr på information og data.

En database giver overblik og gør det nemmere at gemme og vedligeholde oplysninger.

Webhosting

  • Delt hosting – velegnet til hjemmesider og blogs.
  • VPS-hosting – giver flere muligheder og kontrol.
  • Cloud-hosting – data gemmes på eksterne servere.

SQL

SQL står for Structured Query Language og bruges til at oprette, hente og administrere databaser.

HTML

Du kan se andre hjemmesiders HTML-kode ved at højreklikke på siden og vælge "Inspicer".

HTML-tags

  • <strong> – vigtig tekst
  • <i> – kursiv tekst
  • <mark> – markeret tekst
  • <small> – mindre tekst
  • <del> – slettet tekst
  • <sub> – sænket tekst
  • <sup> – hævet tekst
  • <address> – kontaktoplysninger
  • <cite> – titel på værk

CSS

CSS bruges til at ændre farver, skrifttyper, størrelser og layout på hjemmesider.

  • Inline CSS
  • Internal CSS
  • External CSS
