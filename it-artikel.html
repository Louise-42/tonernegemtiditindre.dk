IT-værksted | Toner fra hjertet

At eje en pc kræver, at man holder den ved lige. Men det kan være svært, hvis man er ny bruger. Hvor starter man, og hvilke programmer bør man have installeret?

Mange vil nok sige, at antivirus er en høj prioritet. En computer er hele tiden udsat, når man bruger internettet, og derfor er sikkerhed en vigtig del af en stabil pc.

Programmer til en god pc-opstart

💾

En god start kan være et program som Wise Care 365. Programmet kan hjælpe med at fjerne unødvendige filer, rydde op på computeren og gøre opstarten hurtigere.

🛠️

Wise Care 365 kræver ikke stor teknisk viden. Med få klik kan programmet scanne computeren, finde problemer og guide brugeren igennem processen.

🌐

Google Chrome er en af de mest kendte internetbrowsere. Den bruges til at besøge hjemmesider og kan forbindes med en Google-konto.

Der findes dog flere forskellige browsere. Firefox er et andet gratis alternativ, som mange brugere vælger på grund af fokus på privatliv.

Malwarebytes er også et vigtigt sikkerhedsprogram. Ved hjælp af scanning kan programmet finde spyware, malware og andre sikkerhedstrusler på computeren.

Wise Program Uninstaller er et nyttigt program, hvis man ønsker at fjerne software helt fra computeren. Det kan hjælpe med at fjerne programmer, som Windows normale afinstallation ikke altid fjerner fuldstændigt.

Når man bruger internettet, udsætter man sig samtidig for risikoen for virus og andre angreb. Programmer som AVG kan hjælpe med beskyttelse og advare brugeren, hvis en trussel opdages.

VLC Media Player er et meget populært videoprogram. Det kan afspille mange forskellige filtyper og fungerer på flere platforme som Windows og Linux.

Med VLC kan man blandt andet tilføje undertekster, ændre lydspor og bruge mange andre funktioner.

Hardware – Computerens indre dele

💻

En computer består af mange forskellige hardwaredele, som arbejder sammen for at få systemet til at fungere.

🧠

RAM er computerens arbejdshukommelse. Når man ser videoer, spiller spil eller arbejder med programmer, bruger computeren RAM til midlertidig data.

⚡

Jo mere krævende programmer man bruger, jo mere RAM kan computeren have brug for for at arbejde hurtigt og stabilt.

💿

Der findes forskellige former for lagerenheder. HDD er traditionelle harddiske, mens SSD er nyere og hurtigere lagringsteknologi.

🚀

SSD kan ofte give en gammel computer nyt liv, fordi programmer og Windows starter hurtigere.

💾

Når computeren slukkes, forsvinder indholdet i RAM. Derfor gemmes filer permanent på harddiske eller SSD'er.

🎮

Hvor meget RAM man bør have afhænger af, hvad computeren skal bruges til. En gamer-pc kræver ofte mere RAM end en computer der kun bruges til internet og tekstbehandling.

📊

Man kan kontrollere computerens RAM-forbrug gennem Windows Jobliste (Task Manager). Her kan man se, hvilke programmer der bruger flest ressourcer.

🎮

Hvis computeren bliver langsom, fryser eller har problemer med at åbne programmer, kan det skyldes, at systemet mangler RAM eller har langsom lagring.

🎮

Det anbefales dog ikke, at uerfarne brugere selv udskifter hardware uden at vide præcis, hvad computeren understøtter.

🎮

Motherboardet er computerens hovedkort. Det forbinder alle computerens komponenter og sørger for kommunikationen mellem hardwaredelene.

🎮

Under opstart kontrollerer motherboardets chip, at computerens hardware fungerer korrekt.

🎮

CPU'en er computerens hjerne. Den behandler information og styrer programmer, grafikkort og andre komponenter.

🎮

De mest kendte CPU-producenter er Intel og AMD. Processorens hastighed måles blandt andet i GHz, som beskriver hvor mange beregninger processoren kan udføre.

Databaser og XAMPP

🎮

En database bruges til at gemme og organisere information. Virksomheder bruger databaser til at holde styr på deres produkter, kunder, komponenter og andre oplysninger.

XAMPP er et program, som kan bruges til at oprette et lokalt udviklingsmiljø med blandt andet Apache, PHP og MySQL.

Med XAMPP kan man arbejde med databaser på sin egen computer gennem en webbrowser og teste hjemmesider, før de bliver lagt online.

En database kan eksempelvis bruges til at oprette afdelinger, ID-numre og underkategorier. Hvis en fejl bliver rettet ét sted, kan ændringen automatisk bruges andre steder i systemet.

Fordelen ved en database er, at virksomheder får bedre overblik over deres udstyr og information. Data kan organiseres, vedligeholdes og findes hurtigt.

Apache og servere

Apache er en webserver, som bruges til at vise hjemmesider og håndtere forespørgsler mellem bruger og server.

Apache kan bruges i virksomheder, hvor medarbejdere gennem et netværk kan få adgang til bestemte systemer og informationer.

En løsning kan være at oprette en VPS-server, hvor man får mere kontrol over serverens funktioner og kan tilpasse den efter behov.

VPN og sikker forbindelse

En vigtig del af moderne netværk er sikkerhed. VPN bruges til at skabe en krypteret forbindelse, så data bliver beskyttet under overførsel.

VPN kan gøre det mere sikkert at bruge trådløse netværk, fordi forbindelsen mellem bruger og netværk bliver beskyttet.

Webhosting

Der findes flere forskellige former for webhosting. Valget afhænger af, hvor meget kontrol og kapacitet man har brug for.

  • Delt hosting – bruges ofte til hjemmesider og blogs. Flere brugere deler samme server.
  • VPS-hosting – giver mere kontrol og flere muligheder. Bruges ofte af virksomheder, der ønsker større frihed.
  • Cloud-hosting – bruger flere servere, hvor ressourcer kan skaleres efter behov.

Cloud og virtuelle datacentre

Cloud-løsninger giver virksomheder mulighed for at placere deres data på eksterne servere.

Et virtuelt datacenter (VDC) giver mulighed for at justere ressourcer som lagerplads og RAM, efter hvor meget virksomheden har brug for.

Et VDC kan også indeholde sikkerhedsløsninger som firewalls og backup-systemer, så data kan beskyttes bedre.

SQL – Databasernes sprog

SQL står for Structured Query Language. Det er et programmeringssprog, der bruges til at oprette, hente og ændre data i databaser.

SQL gør det muligt at arbejde struktureret med information gennem tabeller, kolonner og rækker.

Et vigtigt princip i databaser er at bruge ensartede navne og faste strukturer, så information kan forstås af forskellige personer og systemer.

Et eksempel er SKU (Stock Keeping Unit), som bruges til at identificere produkter med et unikt nummer eller navn.

SQL står for Structured Query Language. Det er et databasesprog, som bruges, Sammen med HTML, PHP og andre teknologier kan SQL bruges til at skabe dynamiske hjemmesider med databaser bagved.

HTML – Grundlaget for hjemmesider

HTML står for HyperText Markup Language og bruges til at opbygge strukturen på hjemmesider.

Hvis man vil se andre hjemmesiders HTML-kode, kan man højreklikke på siden og vælge "Inspicer". Herefter åbnes udviklerværktøjer i browseren.

Et HTML-dokument starter normalt med:

  • <!DOCTYPE html> – fortæller browseren, hvilken HTML-version dokumentet bruger.
  • <html> – indeholder hele HTML-dokumentet.
  • <head> – indeholder information om siden.
  • <title> – viser sidens titel i browserfanen.
  • <body> – indeholder selve indholdet, som brugeren kan se.

Et HTML-dokument bør kun have én body-sektion, da den indeholder hele sidens synlige indhold.

HTML elementer og attributter

HTML består af elementer, som fortæller browseren, hvordan indholdet skal vises.

Attributter giver ekstra information til elementerne. Et eksempel er navn og værdi, som kan ændre et elements egenskaber.

HTML styrer strukturen på en hjemmeside, mens CSS bruges til selve udseendet.

PHP og dynamiske hjemmesider

PHP er et programmeringssprog, som kører på serveren.

PHP kan bruges til at behandle filer, oprette databaser og håndtere information mellem bruger og server.

PHP kan blandt andet sende og modtage cookies samt bruges til kontrolleret adgang gennem brugerlogin.

Hjemmesider lavet med PHP kan være dynamiske, hvor indholdet ændrer sig efter brugerens handlinger.

HTML er derimod normalt mere statisk, fordi strukturen er skrevet direkte i dokumentet.

HTML-tags

  • <strong> – vigtig tekst
  • <i> – kursiv tekst
  • <mark> – markeret tekst
  • <small> – mindre tekst
  • <del> – slettet tekst
  • <ins> – indsat tekst
  • <sub> – sænket tekst, eksempel H₂O
  • <sup> – hævet tekst, eksempel fodnoter
  • <address> – kontaktoplysninger
  • <cite> – titel på værk som sang, film eller maleri
  • <bdo> – ændrer tekstretning, eksempelvis højre mod venstre
  • <br> – linjeskift
  • <pre> – formateret tekst

CSS – Cascading Style Sheets

CSS bruges til at ændre hjemmesiders udseende. Med CSS kan man styre farver, skrifttyper, størrelser, afstande og layout.

CSS kan tilføjes til HTML på tre forskellige måder:

  • Inline CSS – CSS direkte inde i HTML-elementet.
  • Internal CSS – CSS skrevet i en style-sektion inde i HTML-filen.
  • External CSS – en separat CSS-fil, som forbindes med HTML gennem et link.

CSS farver

CSS understøtter flere måder at beskrive farver på.

  • RGB – rød, grøn og blå. Værdier går normalt fra 0 til 255.
  • HEX – farvekoder som eksempelvis #00f0ff.
  • HSL – farve, mætning og lysstyrke.
  • RGBA – RGB med gennemsigtighed.
  • HSLA – HSL med gennemsigtighed.

Programmer til kodning

Visual Studio Code er et populært program til at skrive HTML, CSS og JavaScript.

Programmet giver mulighed for udvidelser, fejlfinding og en bedre arbejdsproces ved udvikling af hjemmesider.

XAMPP opsætning

XAMPP bruges til at arbejde med databaser og lokale hjemmesider.

Åbn XAMPP og start Apache og MySQL. Herefter kan man arbejde med databaser gennem phpMyAdmin.

XAMPP gør det muligt at teste hjemmesider lokalt, før de bliver lagt online.
